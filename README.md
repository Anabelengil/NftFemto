# NftFemto

Syncs cryptocurrency transaction data with local storage for fast offline access and easy data backup.

With NftFemto, you get a lightweight tool that stays out of your way.

**What you get**

- Syncs cryptocurrency transaction data with
- local storage for fast offline
- access and easy data backup

## Key Features

- Syncs cryptocurrency transaction data with
- local storage for fast offline
- access and easy data backup

## Technology Stack

- php
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftFemto.git`
2. `cd NftFemto`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NftFemto, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
